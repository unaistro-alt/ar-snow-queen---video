# AR-отчёт: Снежная королева

## Статус
Модель экспортирована и проверена. Готова к демонстрации на маркере.

## Артефакты
- `snow_queen_v1.glb` — модель Снежной королевы (экспорт из Blender 5.0, Draco-сжатие включено).
- `index.html` — демонстрация в AR.js + A-Frame.
- `markers/` — два паттерн-маркера (для GLB и для видео).
- `video_placeholder.txt` — место под видео-секвенцию с альфа-каналом (будет добавлено позже).

## Как запустить
1. Положить маркеры перед камерой.
2. Открыть `index.html` на устройстве с камерой (телефон или ПК).
3. При наведении на маркер 1 появится 3D-модель.
4. На маркере 2 пока стоит заглушка — туда планируется видео с прозрачностью.

## Что уже сделано
- Модель корректно ориентирована (Y Up).
- Масштаб приведён к реалистичному (рост ~2 м).
- Применены модификаторы, веса арматуры сохранены.
- Включено Draco-сжатие для уменьшения размера файла.
